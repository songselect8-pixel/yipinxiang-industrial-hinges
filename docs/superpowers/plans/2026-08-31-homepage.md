# Industrial Hinge Homepage Implementation Plan

> Execution: inline in this task. The user approved the sitemap and information architecture and explicitly authorized the homepage only. No subagents, additional pages, public deployment or contact publication are needed.

**Goal:** Build a polished, working English-language industrial hinge homepage with original product photography and accurate specification-to-inquiry interactions.

**Architecture:** Next.js App Router with server-rendered content and small client components for navigation, native specification disclosures and RFQ state. The original source audit remains private; public catalog records contain only selected nonpersonal fields. All navigation targets existing homepage sections.

**Tech stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, local IBM Plex Sans. Browser QA uses the bundled Playwright runtime.
